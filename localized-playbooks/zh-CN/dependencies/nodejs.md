### Node.js

Node.js 22.22.1 LTS 是该平台推荐的版本。

<!-- @os:windows -->
1. 从 [nodejs.org](https://nodejs.org/zh-cn/download/) 下载 Windows 64-bit Installer。
2. 运行安装程序并按提示操作。
3. 验证安装：

```cmd
node --version
npm --version
```
<!-- @os:end -->

> **注意**：如需其他安装选项和平台信息，请参阅 [Node.js Downloads](https://nodejs.org/zh-cn/download/)。
